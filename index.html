About NIT Silchar Hackathon 2026

The National-Level Coding Competition Hackathon 2026 is organized by NIT Silchar, a premier institute recognized for technical education and research in India. This three-round competition aims to provide a national platform for coding excellence, encourage innovation in AI/ML solutions, foster collaboration among students, identify top talent, and provide real-world problem-solving exposure.

TEAM REQUIREMENTS & RULES

Important information for all participants

TEAM COMPOSITION

✓ Maximum 3 members
✓ Each team must designate one Team Leader
✓ All members must be current students (ID proof required)
✓ Cross-college teams are allowed

SUBMISSION REQUIREMENTS

✓ Deadline: November 15, 2025, 11:59 PM
✓ Submit complete source code folder to Google Drive
✓ Include comprehensive README file with:
   - Project description
&    - Installation instructions
   - Team member names and roles
   - Technologies used
   - Screenshots/Demo links
✓ Only Team Leaders get upload access to Google Drive
✓ Late submissions will not be accepted

PRESENTATION REQUIREMENTS

✓ Each team must present their work in scheduled tutorial class
✓ Presentation duration: 10-15 minutes
✓ Include live demo or video demonstration
✓ All team members should participate
✓ Q&A session will follow presentation
